Get started

About a minute. You will not type your password into a chat at any point.

  1. Save the number. loading — or just tap Open in WhatsApp.
  2. Join the sandbox. Send the exact phrase loading. This is a Twilio test number, so every new device sends this once.
  3. Link your account. Send link. You get a private page that works once and expires in ten minutes. You sign in there, on HTTPS.
  4. Ask it something. Try what are my units.

What it will never do

These are refused in code, not just discouraged by a prompt.

Submit your coursework, or upload a file on your behalf
Open, answer or submit a quiz
Read or write any grade
Post to a forum in your name

It fetches the questions and the material. You do the work and you submit it. That line is deliberate: an agent that could hand in your assignment is a cheating tool, not a study tool.

Is it stored?No. It is swapped for an access token in a single request, then discarded. Never logged.

How it works

For the judges, and for anyone who wants to fork it.

WhatsApp → Twilio webhook → FastAPI on Cloud Run → Google ADK agent → e-learning web-service API

Two paths, chosen explicitly

The agent has a browser (Playwright MCP, DOM-first with a Gemini vision fallback for anything the accessibility tree cannot expose) and it has a REST toolset. The e-learning site is always reached over REST, never the browser: the site allows one interactive session per user, so a headless login there could log a student out of their own laptop mid-class. Token calls do not consume that session, which is also why many students can use the bot at the same time.

Many students, one deployment

Each student holds their own token. Sessions and store keys are salted hashes of the phone number, so the datastore is not a list of student numbers. Turns are serialised per sender and run concurrently across senders, with a cap on total in-flight work.

Guardrails

A server-side allowlist decides which API functions can be called at all, and a second independent denylist permanently blocks submission, quiz and grade functions. Anything state-changing stops and asks for a plain-language YES first. Course content is treated as untrusted data, so a prompt hidden in a slide deck cannot redirect the agent.
